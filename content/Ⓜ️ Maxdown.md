# Ⓜ️ Maxdown

## 자리 표시자

- `{Content}` => 임의의 문자열
- `{Value}` => 임의의 정수 및 실수

## 문법

### 구조

### 텍스트

#### 볼드

**권장**

```
**{Content}**
```

---

**호환**

```
__{Content}__
```

#### 이탤릭

**권장**

```
*{Content}*
```

---

**호환**

```
_{Content}_
```

#### 취소선

```
~~{Content}~~
```

#### 밑줄

```
~{Content}~
```

#### 위 첨자

```
^^{Content}^^
```

#### 아래 첨자

```
,,{Content},,
```

#### 상단 루비 문자

```
^^{Content:Base} | {Content:Ruby}^^
```

#### 하단 루비 문자

```
,,{Content:Base} | {Content:Ruby},,
```

#### 하이라이트

```
=={Content}==
```
