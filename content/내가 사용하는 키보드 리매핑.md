# 내가 사용하는 키보드 리매핑

(**Original** => **Modified**)

- **Caps Lock** => Language Switch
  - 흔히 부르는 명당 자리에 한국에서 많이 쓰는 키를 할당
  - MacBook / iPad Magic Keyboard 의 Caps Lock 대체와 유사
- **Left Ctrl** => Left Win
  - 가끔씩 쓰는 키를 구석에 할당
  - 가장 약한 새끼 손가락으로 눌러도 많이 쓰지 않으니 괜찮음
- **Left Win** => Left Alt
  - 쏠쏠하게 쓰는 키를 남는 자리에 할당
  - 엄지 손가락으로 누를 수 있어 Alt+Tab 시 생각보다 불편하지 않음
- **Left Alt** => Left Ctrl
  - 가장 많이 쓰는 키를 엄지 손가락으로 누르게 할당
  - macOS 의 cmd 키와 역할도 위치도 유사하게 함
- **Right Alt** => Hanja
  - 한국어권에 기호 입력에 많이 쓰는 키를 엄지 손가락에 할당
  - 오른쪽 모디파이어는 왼쪽 모디파이어보다 사용 빈도가 매우 적음
- **Right Win** => Menu
  - 키보드 작업 시에 유용한 키를 오른쪽 모디파이어에 할당
  - 이미 그렇게 할당되어있는 키보드의 경우 매핑하지 않음
- **Right Ctrl** => Left Win + Left Shift + F23
  - 가장 구석에 AI 호출 키를 할당
  - Copilo Laptop 의 Copilot 키가 내부적으로 호출하는 단축키로 2024 년부터 현재까지 사용됨
- **Right Shift** => Backspace
  - 매우 자주 쓰는 삭제 키를 손을 뻗지 않고 새끼 손가락으로 누르도록 할당
  - 오른쪽 Shift 는 왼손이 어차피 키보드에 고정되어있기에 잘 안 씀
- **Backspace** => Delete
  - 후방 문자 삭제 키를 전방 문자 삭제 키와 대칭을 이루도록 할당
  - 손을 멀리 뻗지 않고도 사용 가능하게 함
- **Delete** => Caps Lock
  - 갈 곳을 잃은 키를 남는 여유 공간에 할당
  - 같은 입력 관련 토글 키인 Insert 와 대칭을 이룸
